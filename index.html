MÓDULO 01 · FUNDAMENTOS

¿Qué es la distribución de Poisson?

Empecemos con la pregunta que este modelo estadístico permite responder.

01/10
◎

Un modelo para contar eventos

La distribución de Poisson es una distribución de probabilidad discreta que modela el número de veces que ocurre un evento dentro de un intervalo definido de tiempo, espacio o región, bajo ciertas condiciones.

En lugar de medir cuánto dura algo, contamos cuántas veces sucede.

Por ejemplo ¿Cuántas llamadas recibe un servicio de urgencias en una hora?
LA VARIABLE ALEATORIA
X ∈ {0, 1, 2, 3, …}

X representa una cantidad de ocurrencias: 0 llamadas, 1 llamada, 2 llamadas, etc.

No puede tomar valores como 1,5 llamadas.

MÓDULO 04 · ALGORITMO DE DECISIÓN

¿Cuándo conviene usar Poisson?

Evaluá las condiciones antes de utilizar el modelo. No se aplica automáticamente a cualquier conteo.

04/10

Condiciones que conviene revisar

  • ✓
    Variable de conteo. Interesa el número de ocurrencias, no una duración ni una medida continua.
  • ✓
    Intervalo definido. Se observa un período o una región concreta.
  • ✓
    Tasa estable. El promedio de ocurrencias por unidad se mantiene aproximadamente constante.
  • ✓
    Independencia aproximada. Que ocurra un evento no altera sustancialmente la probabilidad de los siguientes.
En el modelo clásico de proceso de Poisson, la probabilidad de dos o más eventos en un intervalo muy pequeño es despreciable. Los eventos no tienen que ser siempre «raros» para utilizar Poisson.

MÓDULO 05 · SIGNIFICADO

El parámetro λ (lambda)

Una sola cantidad controla el comportamiento de la distribución.

05/10
VALOR MEDIO EN EL INTERVALO
λ

Lambda es el promedio esperado de ocurrencias.

Es un número mayor que cero. No es una probabilidad: puede valer 0,5; 4 o 12, entre otros valores.

λ > 0
CAMBIAR EL INTERVALO

Si llegan 4 pacientes por hora…

30 minλ = 2
1 horaλ = 4
2 horasλ = 8

Al cambiar la longitud del intervalo, ajustamos el promedio esperado, si la tasa se mantiene constante.

λ del intervalo = tasa × duración
MÓDULO 06 · CÁLCULO

Función de probabilidad

La fórmula permite calcular la probabilidad de observar una cantidad exacta de eventos.

06/10
FUNCIÓN DE PROBABILIDAD PUNTUAL
P(X = x) = e−λ · λxx!
x = 0, 1, 2, … • λ > 0
FUNCIÓN DE DISTRIBUCIÓN ACUMULADA

Para calcular la probabilidad de como máximo k eventos, sumamos las probabilidades desde 0 hasta k.

P(X ≤ k) =k∑i=0e−λ · λii!
xCantidad exacta de eventos
λPromedio del intervalo
eConstante ≈ 2,71828
x!Factorial de x

¿Y la probabilidad acumulada? Para encontrar P(X ≤ x), sumamos las probabilidades desde 0 hasta x. Para «al menos x», usamos el complemento: P(X ≥ x) = 1 − P(X ≤ x − 1).
MÓDULO 07 · MEDIDAS

Esperanza y varianza

Poisson tiene una propiedad característica: ambas son numéricamente iguales.

07/10
ESPERANZA MATEMÁTICA
E(X) = λ

Es el número promedio esperado de ocurrencias en el intervalo.

VARIANZA
Var(X) = λ

Indica la dispersión de los conteos respecto de su media.

DESVIACIÓN ESTÁNDAR
σ = √λ

Expresa la dispersión en las mismas unidades de conteo.

Si λ = 4, entonces la esperanza es 4, la varianza es 4 y la desviación estándar es 2.

MÓDULO 09 · PRÁCTICA GUIADA

Un ejemplo contextualizado

Retomamos el problema de llamadas que aparece en la ficha conceptual del grupo.

09/10
☎
CASO · SERVICIO DE ATENCIÓN

Un servicio recibe, en promedio, 4 llamadas por hora.

¿Cuál es la probabilidad de que en una hora reciba exactamente 3 llamadas? ¿Y como máximo 3?

1

Definir la variable

X = número de llamadas recibidas en una hora.

X ~ Poisson(4)
2

Identificar los datos

El promedio para una hora es λ = 4. Para la primera pregunta, x = 3.

λ = 4 · x = 3
3

Calcular e interpretar

Aplicamos la función puntual para exactamente 3 y la acumulada para hasta 3.

P(X=3) ≈ 0,1954
EXACTAMENTE 3 LLAMADAS19,54 %

P(X = 3) = e−4 · 43 / 3! ≈ 0,1954.

COMO MÁXIMO 3 LLAMADAS43,35 %

P(X ≤ 3) = P(0) + P(1) + P(2) + P(3) ≈ 0,4335.

Interpretación: bajo el modelo de Poisson con promedio de 4 llamadas por hora, hay aproximadamente un 19,54 % de probabilidad de recibir exactamente 3 llamadas y un 43,35 % de recibir 3 o menos.
EJERCICIO 2 · PARA RESOLVER CON LA CLASE

Mensajes que llegan a un servidor

Un servidor recibe en promedio 2 mensajes por minuto (λ = 2). ¿Cuál es la probabilidad de que en un minuto no llegue ningún mensaje? ¿Y de que llegue al menos uno?

Fácil
Mostrar la resolución paso a paso ↓

Exactamente cero: P(X = 0) = e−2 · 20 / 0! = e−2 ≈ 0,1353 = 13,53 %.

Al menos un mensaje: P(X ≥ 1) = 1 − P(X = 0) ≈ 0,8647 = 86,47 %.

Interpretación: hay aproximadamente un 86,47 % de probabilidad de recibir al menos un mensaje durante el minuto observado.

PARA IR UN POCO MÁS ALLÁ

¿Y si la variable original fuera binomial?

Cuando hay muchos ensayos y una probabilidad individual pequeña, Poisson puede funcionar como aproximación de una Binomial con λ = n · p. La calidad de la aproximación depende de los valores de n y p; las reglas vistas en la ficha son orientativas, no garantías universales.
